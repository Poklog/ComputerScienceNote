                                                                 根據提供的來源資料，在建立 AI 模型時，**資料分割（Data Splitting）** 是為了==評估模型性能==、==防止過擬合==，並確保模型具備泛化能力的關鍵步驟。


- 基礎分割方法 (Train/Test Split
	將原始數據集按比例（如 8:2 或 7:3）切分為「訓練集」與「測試集」
	- **[[隨機分割]] (Random Split)**：
		- **適用情境**：數據點彼此獨立且分佈均衡，常用於**一般回歸問題**（如預測房價）或類別數量充足的**一般分類問題**。
	- **[[分層分割]] (Stratified Split)**：
		- **適用情境**：**類別不平衡的分類問題**（如醫療診斷、信用卡詐騙），防止測試集中完全沒有少數類別的樣本。
	- **[[時間序列分割]] (Time Series Split)**：
	    - **適用情境**：具時間相依性的數據（如**股市價格、氣象預測**），目的是防止「未來資訊洩漏」（Data Leakage）。

-  進階驗證方法：K-折交叉驗證 (K-fold Cross-Validation)
	當數據量偏少或需要更客觀的評估報告時使用。方法是將數據分成 K 份，輪流作訓練與考卷。
	
	- **整個數據集進行 [[K-fold]]**：
	    - **目的**：用於**模型評估 (Model Evaluation)**，向他人證明演算法在平均狀況下的準確度。
	- **僅在訓練集進行 [[K-fold]]**：
	    - **目的**：用於**模型選擇 (Model Selection)**。先預留 20% 作為最後的「期末考卷」（Hold-out Test Set），剩下的 80% 內再進行 K-fold 模擬考，用來調優模型參數。這被視為工業界的標準做法。

| 分割方法       | 最適合的問題類型    | 核心優點              |
| ---------- | ----------- | ----------------- |
| **隨機分割**   | 一般回歸、均衡分類   | 簡單快速，適合獨立數據       |
| **分層分割**   | 不平衡分類問題     | 確保測試集能反映真實類別比例    |
| **時間序列分割** | 股市、氣象、感測器數據 | 防止模型「預知未來」，符合現實邏輯 |
| **K-fold** | 數據中等或偏少     | 評估穩定性較高，不帶運氣成分    |
