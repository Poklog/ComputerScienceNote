### 基本定義與目的

- **誤差量化**：損失函數將預測誤差轉換為一個數值表示。這個數值越小，代表模型的預測越接近真實目標，性能也就越好。
- **模型優化**：在模型訓練過程中，主要的目標就是通過不斷調整參數，讓損失函數的值降到最低。

### 理想損失函數的特性

一個好的損失函數應具備以下特點，以利於電腦進行運算：

- ==**不可抵消性**==：為了避免正負誤差相互抵消（例如誤差 -100 與 +100 加總為 0 的誤判），通常會使用絕對值或平方處理。
- ==**可微分性**==：函數曲線必須平滑，以便電腦計算梯度（斜率），進而利用**[[梯度下降]]（Gradient Descent）**來修正模型參數。
- ==**合理懲罰大誤差**==：好的損失函數會讓誤差越大時，Loss 增長得越快，進而產生更大的梯度來加快修正速度。
- ==**數值穩定**==：計算過程中數值不能突然爆炸或變得無限小，以確保運算正常。

### 常見的損失函數類型

根據不同的任務需求，會選擇不同的損失函數：

- **數值預測（回歸問題）**：常用的包括 **MSE（平均平方誤差）**、**MAE（平均絕對誤差）** 及 **Huber 損失**。
    - _MSE_ 會放大較大的誤差（懲罰大誤差），適合大多數情況。
    - _MAE_ 對異常值（Outlier）較具抗性（Robust）。
- **分類問題**：
    - **二分類**：常用 **BCE（二元交叉熵）**。
    - **多分類**：常用 **Softmax CE（交叉熵）**。
    - **不平衡樣本**：可用 **Focal Loss** 來調整難易樣本的權重。

### 在訓練中的角色（梯度下降）

損失函數在訓練中扮演「山脈」的角色，站立的位置代表目前的模型參數，而**海拔高度就是損失值**。訓練的過程就像是「摸黑下山」，透過計算梯度（坡度）並朝著最陡的下方邁進（更新參數），最終目標是找到整座山脈海拔最低的地點，即**全域最小值（Global Minimum）**，此時模型的預測最為精準

### 程式碼
```python
import pandas as pd
import numpy as np

# 1. 模擬從 CSV 讀取的資料 (真實值 y 與 模型預測值 y_pred)
data = {
    'actual_y': [10.0, 12.5, 11.0, 15.0, 30.0],  # 最後一筆是極端值
    'predict_y': [10.5, 12.0, 10.8, 14.2, 20.0]
}
df = pd.DataFrame(data)

# 2. 計算 L1 Loss (絕對誤差 MAE)
df['L1_Loss'] = (df['actual_y'] - df['predict_y']).abs()

# 3. 計算 L2 Loss (平方誤差 MSE)
df['L2_Loss'] = (df['actual_y'] - df['predict_y'])**2

print("--- 逐筆資料的損失值 ---")
print(df)

# 4. 計算整體的平均損失 (Cost Function)
mae = df['L1_Loss'].mean()
mse = df['L2_Loss'].mean()

print(f"\n整體平均 L1 損失 (MAE): {mae:.2f}")
print(f"整體平均 L2 損失 (MSE): {mse:.2f}")
```
