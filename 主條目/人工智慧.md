**模型建立五步驟**：匯入套件、資料清理、建立模型、訓練模型、模型評估。
- **第一、二章：線性回歸**(Regression)
	- [[回歸分析]]
		- [[OLS]] (Ordinary Least Squares, 普通最小平方法)
		- [[TLS]] (Total Least Squares, 總體最小平方法)
	- [[誤差量化]]
		- [[MAE]] (Mean Absolute Error, 平均絕對誤差)
		- [[MSE]] (Mean Squared Error, 平均平方誤差)
		- [[RMSE]] (Root Mean Squared Error, 均方根誤差)
		- [[偏差]] (Bias)
		- [[變異]]/方差 (Variance)
	- [[資料預處理]]
		- [[正規化]] (Normalization / Min-Max Scaling)
		- [[標準化]] (Standardization / Z-Score Scaling)
	- [[模型擬合]]
		- 欠擬合 (Underfitting)
		- 過擬合 (Overfitting)
	- [[損失函數]]
		- [[梯度下降]] (Gradient Descent)
			- 學習率 (Learning Rate)
			- 最小值 (Minimum)
- **第三章：資料分割與驗證** (Train Test Split)
	- [[資料分割方法]]
	    - [[隨機分割]] (Random Split)
	    - [[分層分割]] (Stratified Split)
	    - [[時間序列分割]] (Time Series Split)
		- [[K-fold]] 

- **第四、五章：分類與邏輯回歸 (Classification LogisticRegression)**
	- [[邏輯回歸]] (Logistic Regression)
		- Sigmoid 
	- [[混淆矩陣]] (Confusion Matrix)
		- [[準確率]] (Accuracy)
		- [[精確度]] (Precision)
		- [[召回率]] (Recall/Sensitivity)
		- 特異度 (Specificity)
		- F1 Score：精確度與召回率的調和平均數。
	- 多類別分類 
		- OvO (One-vs-One, 一對一)
		- OvR (One-vs-Rest, 一對其餘)
		- Softmax (多項式邏輯回歸)
	- [[降維]] (Dimensionality Reduction)
		- 線性降維
			- [[PCA]] (Principal Component Analysis, 主成分分析)
			- LDA (Linear Discriminant Analysis, )
		- 非線性降維 
			- t-SNE
			- UMAP
			- Autoencoder
- **第六章：支援向量機 (Support Vector Machine, SVM)**
	- SVM
	- 原始問題 (Primal)
	- 對偶問題 (Dual)
	- 核技巧 (Kernel Trick)
		- Linear (線性)
		- Polynomial (多項式)
		- RBF / Gaussian (徑向基函數
		- Sigmoid
