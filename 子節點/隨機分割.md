### 方法
系統將數據打亂，並依比例隨機分配。

### 適用情境
 數據點彼此獨立且分佈均衡，常用於**一般回歸問題**（如預測房價）或類別數量充足的**一般分類問題**。
### 關鍵參數
通常會設定 `random_state`（隨機種子），以確保實驗結果可以被重現。

### 程式碼
```python
import pandas as pd
from sklearn.model_selection import train_test_split

# 1. 讀取 CSV 資料 [2]
data = pd.read_csv('lg_sample.csv') 

# 2. 提取特徵 X 和標籤 y [2]
X = data[['性別', '年紀', '天氣溫度']] 
y = data['感冒發生']

# 3. 執行隨機分割 (以 8:2 為例) [5]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, shuffle=True, random_state=42
)
```
