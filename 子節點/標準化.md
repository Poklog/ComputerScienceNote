標準化 (Standardization / Z-Score Scaling)

- **目的：** 將數據轉換為平均值μ為 0，標準差σ為 1 的分布，它將數據集中在 0 附近，絕大部分數據會在 $[−3,3]$ 之間。
	- **適用場景：** 大多數機器學習演算法（如線性回歸、SVM、PCA）。它對偏離值的容忍度比正規化高，且能保持數據的分布特性。

<br>

- **公式：**
$$x_{std}​=\frac {x−μ}{σ}​$$

<br>

- **程式碼：**
```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler

# 1. 讀取資料
data = {'X': [20, 25, 30], 'Y': [40, 60, 80]}
df = pd.DataFrame(data)

# 2. 初始化並進行標準化
std_scaler = StandardScaler()
scaled_data = std_scaler.fit_transform(df[['X', 'Y']])
df_scaled = pd.DataFrame(scaled_data, columns=['X_std', 'Y_std'])

print("--- 標準化後的資料 (平均0, 標準差1) ---")
print(df_scaled)

# 3. 資料還原 (Inverse Transform)
# 這在做完 OLS 回歸預測出 Y_std 後，要換回真實 Y 時最常用
restored_data = std_scaler.inverse_transform(df_scaled)
df_restored = pd.DataFrame(restored_data, columns=['X_restored', 'Y_restored'])

print("\n--- 標準化的原始資料 ---")
print(df_restored)
```
