精確度 (Precision)

- **定義**：在所有被 AI 判定為「正向」的樣本中，真正為正向的比例。核心在於「抓得準不準」。
- **公式**：
$$\frac {辨識正確}{AI辨識為正向}=\frac{TP}{TP+FP}$$

|          | 實際正向         | 實際負向         |
| -------- | ------------ | ------------ |
| **預測正向** | ==真正向 (TP)== | ==偽負向 (FN)== |
| **預測負向** | 偽負向 (FN)     | 真負向 (TN)     |

- **運用場景**：適用於==不能亂抓人==的情況
- **案例分析**：**垃圾郵件過濾**。我們寧可漏掉一封垃圾信（召回率低），也不希望把老闆發來的重要郵件誤判為垃圾郵件，因此精確度必須極高。
