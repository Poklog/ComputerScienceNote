召回率 (Recall / 敏感性)

- **定義**：在所有真正為「正向」的樣本中，成功被 AI 抓出來的比例。核心在於「有沒有漏網之魚」。
- **公式**：
$$\frac {預測出正向}{真正為正向}=\frac{TP}{TP+FP}$$

|          | 實際正向         | 實際負向     |
| -------- | ------------ | -------- |
| **預測正向** | ==真正向 (TP)== | 偽負向 (FN) |
| **預測負向** | ==偽負向 (FN)== | 真負向 (TN) |

- **運用場景**：適用於==寧可錯殺一百，不可放過一個==的情況，即偽負向（FN）的代價極大時。
- **案例分析**：**癌症篩檢**或**地震警報**。我們寧可讓健康的人再做一次複檢（誤報），也絕對不能讓一個癌症患者因沒被診斷出來而回家（漏報）。
