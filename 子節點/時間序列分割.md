### 方法
遵循時間順序，以「過去」資料訓練，「未來」資料測試，常採滑動窗口方式。
==遵循時間順序，以過去預測未來==。對於具備時間相依性的數據（如股價、氣象），絕對不能使用隨機打亂，否則會造成「未來資訊洩漏」（Data Leakage）。

### 適用情境
具時間相依性的數據（如**股市價格、氣象預測**），目的是防止「未來資訊洩漏」（Data Leakage）。

### 程式碼
```python
import pandas as pd
from sklearn.model_selection import train_test_split

# 1. 讀取資料集 [1]
# 假設檔案中包含 'date' 欄位與目標值 'price'
data = pd.read_csv('stock_prices.csv') 

# 2. 數據整理：轉換時間格式並執行排序 [1, 2]
# 這是為了確保測試集的時點永遠晚於訓練集 [3]
data['date'] = pd.to_datetime(data['date'])#加上 format 參數來加速轉換：
#pd.to_datetime(data['date'], format='%Y/%m/%d')
data = data.sort_values('date')

# 3. 提取特徵 X 和目標 y [2, 4]
X = data.drop(columns=['price', 'date'])
y = data['price']

# 4. 執行分割：關鍵在於 shuffle=False [5]
# 這能防止資料被隨機打亂，符合時間序列分析的要求 [3, 6]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, shuffle=False
)
```
