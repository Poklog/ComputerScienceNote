正規化 (Normalization / Min-Max Scaling)

- **目的：** 將數據縮放到一個固定的範圍（通常是 $[0,1]$）。

	- **適用場景：** 明確知道數據有邊界，且不希望偏離值（Outliers）影響太大，或是避免資料格式溢位。常用於==影像處理==或==神經網路==。
- **公式：**

$$x_{norm}​=\frac {​x−x_{min}}{x_{max​}−x_{min}}​​$$

<br>

- **程式碼：**
```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler

# 1. 讀取資料 (假設 CSV 有 'X' 和 'Y' 兩個欄位)
data = {'X': [160, 170, 180], 'Y': [50, 70, 90]}
df = pd.DataFrame(data)

#或使用 pandas
df = pd.read_csv('data.csv')
X = df[['feature_x']]
Y = df['target_y'] 

# 2. 初始化並進行正規化
scaler = MinMaxScaler()
# fit_transform 會同時計算 min/max 並轉換
scaled_data = scaler.fit_transform(X,Y)

df_scaled = pd.DataFrame(scaled_data, columns=['X_scaled', 'Y_scaled'])

print("--- 正規化後的資料 (0~1) ---")
print(df_scaled)

# 3. 資料還原回原本的級距
# 直接呼叫 scaler.inverse_transform 即可
original_data = scaler.inverse_transform(df_scaled)
df_restored = pd.DataFrame(original_data, columns=['X_restored', 'Y_restored'])

print("\n--- 還原後的原始資料 ---")
print(df_restored)
```
