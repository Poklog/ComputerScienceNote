準確率 (Accuracy)
- **定義**：整體預測正確的比例，包含正向與負向樣本的正確判斷。
- **公式**：
$$\frac {預測正確資料}{總資料}=\frac{TP+TN}{TP+FP+TN+FN}$$

|          | 實際正向     | 實際負向     |
| -------- | -------- | -------- |
| **預測正向** | 真正向 (TP) | 偽負向 (FN) |
| **預測負向** | 偽負向 (FN) | 真負向 (TN) |

- **運用場景**：==適用於資料分佈非常均衡的情境==。例如：在一組包含 50 名健康人士與 50 名患者的實驗中，準確率是很好的衡量標準。
- **注意陷阱**：==在**資料不平衡**時會產生誤導==。例如在 10,000 人中只有 10 人生病的案例中，如果 AI 懶惰地預測「所有人均健康」，其準確率仍高達 99.9%，但它卻漏掉了所有病人，在醫療場景中是徹底的失敗。
