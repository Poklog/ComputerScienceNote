### 方法
分割時參考目標標籤的比例，確保訓練集與測試集的類別分佈與原始數據一致。
### 適用情境
**類別不平衡的分類問題**（如醫療診斷、信用卡詐騙），防止測試集中完全沒有少數類別的樣本。

Ex：當資料分佈極端不平均（例如 90% 健康、10% 患病）時，必須使用分層分割，否則測試集可能完全沒有少數類別的樣本，導致評估失真

分層分割**不適用於回歸問題**，因為回歸的目標是連續數值，沒有明確的「類別」可以進行分層（除非先手動將數值分組）

### 程式碼
```python
import pandas as pd
from sklearn.model_selection import train_test_split

# 1. 讀取 CSV 資料 [2]
data = pd.read_csv('lg_sample.csv') 

# 2. 提取特徵 X 和標籤 y [2]
X = data[['性別', '年紀', '天氣溫度']] 
y = data['感冒發生']

# 3. 執行隨機分割 (以 8:2 為例) [5]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, shuffle=True, random_state=42 stratify=y
    # stratify=y 確保分割後的標籤比例與原資料相同
)
```
