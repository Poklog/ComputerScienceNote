### 核心比喻：摸黑下山法

資料中將梯度下降比喻為在深夜的濃霧中下山，因為看不清全貌，只能透過腳下的坡度來決定前進方向。

- **目標**：找到海拔最低的地點，即==全域最小值==（Global Minimum），此時模型預測最精準。
- **導航限制**：只能感受到當前位置的坡度，無法一眼看到終點。

### 演算法的三大步驟

- **感受坡度（計算梯度）**：用腳踩踩看哪個方向最陡、向下傾斜最厲害。在數學上是對損失函數進行微分，找出下降最快的方向。
- **邁出一小步（學習率）**：朝著最陡的下方跨出一小步。這一步的大小稱為**學習率（Learning Rate）**。
- **重複動作（迭代與收斂）**：每走一步就重新感受坡度並修正方向，直到四周變平坦（梯度接近 0），代表已達到最小值點，模型訓練完成。

### 學習率 (Learning Rate)

學習率決定了每次更新參數時「走多遠」：

- **太小**：需要非常多次更新才能到達最低點，訓練效率低。
- **太大**：可能會在最低點附近劇烈震盪，甚至越跳越高（發散），無法收斂。
- **適中**：能穩定且迅速地帶領模型抵達最低點。

### 區域最小值 vs. 全域最小值

在優化過程中，地形可能存在多個小窪地：

- **區域最小值 (Local Minimum)**：這只是半山腰的小窪地，雖然四周都往上爬，但並非真正的最低點。演算法若停在此處，代表模型還有進度空間。
- **全域最小值 (Global Minimum)**：整座山脈海拔最低的地點，是所有路徑中的最佳解。

### 線性回歸中的實作邏輯 (Pseudocode)

來源提供線性回歸的梯度下降實作流程：

1. **初始化**：設定初始參數（如 $β=0$）。
2. **計算預測與誤差**：算出預測值 $\hat y$​ 與目標值的誤差。
3. **計算梯度**：利用誤差與特徵矩陣算出目前下降的方向。
4. **更新參數**：**新參數 = 舊參數 - (學習率** α× **梯度)**。
5. **重複**：直到收斂或達到預設的迭代次數。

### 程式碼
```python
import pandas as pd
import numpy as np

# 使用 pandas 讀取 CSV 檔案 [1]
data = pd.read_csv('salary.csv') 

# 提取特徵 X 和目標 y [1]
X_raw = data[['program']].values # 假設特徵欄位為 'program'
y = data[['salary']].values      # 假設目標欄位為 'salary'
n_samples = len(y)

# 資料預處理
# 數據標準化：(原始數據 - 平均值) / 標準差 [2]
X_mean = X_raw.mean(axis=0)
X_std = X_raw.std(axis=0)
X_scaled = (X_raw - X_mean) / X_std

# 初始化參數 [2]
n_features = X_raw.shape[4]
beta = np.zeros(n_features + 1) # 初始化係數為 0
learning_rate = 0.01             # 學習率 (Learning Rate) [2]
iterations = 5000                # 迭代次數 [2]

# 梯度下降演算法實作
# 核心迭代迴圈 [2]
for t in range(iterations):
    # 1. 計算預測值 y_hat = X * beta
    y_pred = X.dot(beta).reshape(-1, 1)
    
    # 2. 計算誤差 error = (y_hat - y)
    error = y_pred - y
    
    # 3. 計算梯度 gradient = (2/n) * X_transpose * error
    gradient = (2 / n_samples) * X.T.dot(error)
    
    # 4. 更新參數 beta = beta - alpha * gradient
    beta = beta - (learning_rate * gradient.flatten())

print("優化後的係數 (含截距):", beta)
```

Q：為何不直接使用數學解 (OLS)？

A：雖然線性回歸可以透過**普通最小平方法 (OLS)** 一次算出精確解，但當資料特徵的維度非常高時，矩陣運算會變得極其昂貴且緩慢。相比之下，**梯度下降法**透過逐步逼近的方式，更適合處理大規模的機器學習任務
